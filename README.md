# Autonomous AI Web Agent Prototype

This project is a prototype for an autonomous AI web agent. It can take a high-level task, generate a multi-step plan using an LLM, and then attempt to execute that plan in a web browser using Playwright. It also features a secure Credential Vault.

## Core Modules & Flow

1.  **Task Orchestrator (`task_orchestrator/main.py`)**:
    *   Entry point: Receives a `user_id` and a high-level `task_description`.
    *   Invokes the **Reasoning Engine**.
2.  **Reasoning Engine (`reasoning_engine/engine.py`)**:
    *   Uses an OpenAI GPT model to convert the `task_description` into a structured, multi-step plan.
    *   The plan consists of steps like `NAVIGATE [URL]`, `CLICK [SELECTOR]`, `FILL [SELECTOR] WITH [TEXT]`, etc.
    *   Returns the plan to the Task Orchestrator.
3.  **Plan Executor (`task_orchestrator/plan_executor.py`)**:
    *   Called by the Task Orchestrator with the generated plan.
    *   Parses each step of the plan.
    *   Invokes corresponding actions in the **Browser Automation** module for each parsed step.
4.  **Browser Automation (`browser_automation/actions.py`)**:
    *   Contains functions that perform actual web interactions (navigation, clicks, typing) using Playwright.
    *   These actions are driven by the Plan Executor.
5.  **Credential Vault (`credential_vault/`)**:
    *   Securely stores user-specific service credentials, encrypted using a master key.
    *   Used by browser automation scripts if login is required (though current plan execution is generic).

## Setup

1.  **Clone the repository.**
2.  **Create a Python virtual environment and activate it.**
3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Install Playwright browser drivers:**
    ```bash
    playwright install
    # You might need to run: playwright install-deps # for Linux system dependencies
    ```
5.  **Configure Environment Variables (`.env` file):**
    Create/update the `.env` file in the project root:
    *   **Credential Vault Master Key:**
        ```env
        CREDENTIAL_VAULT_KEY="your_generated_fernet_key_here"
        ```
        Generate via: `python credential_vault/manage_vault.py generate-key`
    *   **OpenAI API Key:**
        ```env
        OPENAI_API_KEY="your_openai_api_key_here"
        ```
        Required for the Reasoning Engine to generate plans.

6.  **Initialize Credential Vault:**
    ```bash
    python credential_vault/manage_vault.py init-vault
    ```

7.  **Add Credentials (Optional - for specific login tasks):**
    If you plan to test tasks that require login, add credentials. The `browser_automation/login.py` (if used directly) is hardcoded for `test_user_01`/`example_com_login`.
    ```bash
    python credential_vault/manage_vault.py add-credential test_user_01 example_com_login your_web_username your_web_password
    ```

## Running the Autonomous Agent (Task Orchestrator)

The main entry point is `task_orchestrator/main.py`. It will:
1.  Take your task description.
2.  Generate a plan using the LLM (via Reasoning Engine).
3.  Launch a Playwright browser.
4.  Attempt to execute the plan steps.

**Command:**
```bash
python task_orchestrator/main.py <user_id> "<task_description>"
```

**Example:**
```bash
python task_orchestrator/main.py user001 "Navigate to playwright.dev, click on the search button, and type 'getting started'."
```

**Important Considerations for Execution:**
*   **LLM Plan Quality:** The success of execution heavily depends on the quality and accuracy of the plan generated by the LLM. The LLM needs to produce steps that use the defined keywords (`NAVIGATE`, `CLICK`, `FILL`, `READ`, `WAIT`) and provide correct URLs/CSS selectors.
*   **CSS Selectors:** The LLM might hallucinate or provide incorrect/brittle CSS selectors. For reliable execution on specific sites, these selectors often need to be very precise or even dynamically determined. The current implementation relies on the LLM getting them right.
*   **Dynamic Content:** Modern web pages are dynamic. The agent might need more sophisticated waiting mechanisms (e.g., wait for specific elements to be visible/interactive) beyond fixed `WAIT` commands. Playwright itself has auto-waiting capabilities that are utilized to some extent by the action functions.
*   **Error Handling:** The `plan_executor.py` will stop execution on the first error encountered in a step. Logs will indicate where it failed.
*   **Headless Browser:** By default, the browser runs in headless mode (no visible UI). For debugging, you can change `headless=True` to `headless=False` in `task_orchestrator/main.py` within the `launch_browser_and_execute_plan` function.
